# 2.0.3 (25) リリース準備

## App Store「このバージョンの最新情報」

iOS 27で起動直後にアプリが終了する不具合を修正しました。

## 審査メモ

2.0.2 (23) で、iOS 27.0.1の起動時に `UIApplicationEvaluateRuntimeIssueForNoSceneLifecycleAdoption` によるクラッシュを確認しました。UIKitのScene lifecycleへ移行し、SceneDelegateでウインドウを生成するよう修正しています。認証用URL、Universal Links、アプリの復帰イベントを既存のExpo処理へ引き継ぎます。保存データの形式は変更していません。

既存のATT許可時のパーソナライズ広告に合わせてPrivacy Manifestのトラッキング宣言とGoogle広告ドメインを補完しました。App Store Connectのプライバシー回答が既存の広告・IDFA利用と一致することを提出前に確認してください。

## 配信前の実機確認

- iOS 27で通常起動・終了後の再起動ができる。
- 2.0.2から上書き更新して、保存済みペット・在庫・購入履歴が維持される。
- バックグラウンド復帰と通知タップによる商品詳細表示ができる。
- 認証リンクから、終了中・起動中の両方で復帰できる。
- Plus契約の復元と、無料ユーザーの広告表示・同意処理が動く。

## ローカル検証

- `npm run verify:release`: 型チェック、Lint、17テスト、購入頻度・セキュリティ検証に成功。
- EAS production環境＋testflightプロファイルの環境設定検証に成功。
- Xcode 27のシミュレータービルドに成功し、iOS 27でオンボーディング画面を表示。
- 署名なしシミュレーターでは通知SDKのKeychain entitlementエラーが出るため、通知・認証の最終確認は署名付き実機ビルドで行う。

TestFlightアップロード、審査提出、公開は別工程。IPA作成だけで実機確認や配信が完了したことにはならない。
